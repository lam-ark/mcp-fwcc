# 🧬 The SDK Quintet Pattern in Slot Mechanics

---

## 1. The 5 Companion Components
1. **Module**: Visual & animation orchestrator (`SlotBaseModule`).
2. **Data**: Reactive state parser (`BaseDataModule`).
3. **Config**: Constants and timing parameters.
4. **VFX / Items**: Pooled items and Spine effects.
5. **Export & Test**: Barrel export and standalone scene test harness.
