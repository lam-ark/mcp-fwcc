# PaylineInfoModule: Methods & API Reference

---

## 1. `convertPayLineInfoAllWays(paylineInfo: any): any`
* **Purpose**: Formats payout string for AllWays slot systems.

---

## 2. `showPaylineInfo(data: any): void`
* **Purpose**: Displays winning payline info on the bar and activates the node.

---

## 3. `hidePaylineInfo(): void`
* **Purpose**: Hides the payline info bar.
