# PaylineInfoModule: Properties & Configuration

## 1. Cocos Creator Inspector Properties (`@property`)

| Property Name | Data Type | Default | Description |
| :--- | :--- | :---: | :--- |
| **`lbLeft`** | `cc.Label` | `null` | Label displaying line number or payline description. |
| **`lbRight`** | `cc.Label` | `null` | Label displaying formatted win amount (uses `cc.BitmapFont`). |
| **`sprSymbol`** | `cc.Sprite` | `null` | Icon displaying the winning symbol sprite frame. |
| **`useAcrossAllGameModes`** | `boolean` | `false` | If `true`, operates in Normal, Free, and Bonus modes simultaneously. |
