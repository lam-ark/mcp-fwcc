## 1. Production Context

In production games (`g9000L` / `g9666L`):
- `SlotButtonNormal` drives the main spin button with continuous long-press detection for Auto Spins, handles spacebar keyboard triggers on desktop WebGL builds, and cleanly disables input during progressive jackpot presentations.
