# 💾 GameDataStore Internal State & Comprehensive `playSession` Schema

## 1. GameDataStore Internal Runtime State Variables

| Variable Name | TypeScript Type | Default Value | Mutated By | Purpose & Consumers |
| :--- | :--- | :--- | :--- | :--- |
| **`playSession`** | `Record<string, any>` | `{}` | `parseDataPS(data)` | The active round payload received from WebSocket containing matrices, payouts, and mode states. |
| **`freeSpinTimes`** | `number` | `0` | Network packet | Total / initial free spins awarded. Read by `SpinTimesModule`. |
| **`isTrialMode`** | `boolean` | `false` | `TrialModeButton` | Distinguishes virtual demo play from real money wagers. |
| **`gameConfig`** | `GameConfig` | `null` | `setConfig(gameConfig)` | Reference to `GameConfig` for win level thresholds and timings. |
| **`currentGameMode`**| `GAME_MODE_ENUM` | `NORMAL_GAME` (`1`) | Mode directors | Active mode identifier (`NORMAL_GAME`, `FREE_GAME`, `BONUS_GAME`). |

| **`gameModeData`** | `Map<number, any>` | `new Map()` | `updateDataModules()` | Snapshot cache storing previous payload per game mode. |

## 2. 🌟 Exhaustive `playSession` Data Schema & Key Dictionary

`playSession` is the single most critical data payload in the `cc-common` slot engine. It is generated by the server and ingested via `parseDataPS(data)`. Below is the complete catalog of all standard keys and their usage:

### A. Core State & Session Flags
| Key Name | Type | Description & Purpose | Downstream Readers |
| :--- | :--- | :--- | :--- |
| **`state`** / **`mode`** | `number` | Active game mode ID (`1`: Normal, `2`: Free, `4`: Bonus, `8`: Respin). | `SlotTablePaylineData`, Directors |
| **`nextMode`** | `string \| number` | Target mode for next round (e.g. `"2"` for Free Spin trigger). | `GameDataStore.getNextGameMode()` |
| **`isFinished`** | `boolean` | `true` if current cascade/respin sequence has completely finished. | `GameModeDirectorModule.updateWallet()` |
| **`isResume`** | `boolean` | `true` if client is reconnecting/resuming an unfinished spin round. | `FreeGameDirectorModule`, `SlotButtonSpine` |
| **`sessionId`** / **`psId`** | `string` | Unique tracking ID of the spin transaction. | `BetHistoryModule`, `BetCellHistoryModule` |

---

### B. Matrix & Grid Geometries
| Key Name | Type | Description & Purpose | Downstream Readers |
| :--- | :--- | :--- | :--- |
| **`matrix`** | `string[][]` | Active 2D array of symbol strings (e.g. `[['A','K','Q'], ['J','10','9'], ...]`). | `SlotTableData`, `SlotTableModule` |
| **`matrix0`** | `string[][]` | Initial symbol grid before cascade removal or expanding wilds. | `CascadeModuleData` |
| **`normalGameMatrix`** | `string[][]` | Symbol matrix specific to Base/Normal game. | `SlotTableData` |
| **`freeGameMatrix`** | `string[][]` | Symbol matrix specific to Free Spin game mode. | `SlotTableData` |
| **`respinGameMatrix`** | `string[][]` | Symbol matrix specific to Respin feature rounds. | `SlotTablePaylineData` |
| **`bonusGameMatrix`** | `string[][]` | Matrix specific to Pick-and-Click or Mini Bonus boards. | `BonusTableData` |
| **`traceWay`** | `any[]` | Cascade elimination coordinates and dropping step sequences. | `CascadeModuleData` |

---

### C. Win Lines & Monetary Settlement
| Key Name | Type | Description & Purpose | Downstream Readers |
| :--- | :--- | :--- | :--- |
| **`winAmount`** | `number` | Payout earned in the current individual spin step. | `WinAmountModule`, `PaylineInfoModule` |
| **`winAmountPS`** | `number` | Total accumulated payout across the entire play session. | `GameDataStore.getWinAmountPS()` |
| **`totalBet`** | `number` | Total wager amount deducted for the active round. | `GameDataStore.getWinLevel()` |
| **`betId`** | `string` | Wager index ID composed of `betKey + extraBetKey`. | `BetDataModule`, `BonusGameDirector` |
| **`bigWinAmount`** | `number` | Net win amount triggering Big/Mega/Super Win cutscenes. | `GameDataStore.getBigWinData()` |
| **`winType`** | `string \| number` | Win banner tier identifier (`BIG_WIN`, `MEGA_WIN`, `SUPER_WIN`). | `WinEffectModule` |
| **`payLines`** | `object[]` | List of winning payline configurations (line index, symbol, count, payout). | `SlotTablePaylineData`, `PaylineModule` |
| **`normalGamePayLines`** | `object[]` | Mode-specific paylines for Base Game. | `SlotTablePaylineData` |
| **`freeGamePayLines`** | `object[]` | Mode-specific paylines for Free Game. | `SlotTablePaylineData` |
| **`respinGamePayLines`** | `object[]` | Mode-specific paylines for Respin Game. | `SlotTablePaylineData` |
| **`rightPayLines`** | `object[]` | Paylines evaluated right-to-left. | `SlotTablePaylineData` |
| **`jackpotPayline`** | `object` | Winning line triggering the progressive jackpot. | `SlotTablePaylineData` |

---

### D. Free Spins & Feature Multipliers
| Key Name | Type | Description & Purpose | Downstream Readers |
| :--- | :--- | :--- | :--- |
| **`freeGame`** | `number` | Initial count of free spins awarded when entering feature. | `FreeGameDirectorModule` |
| **`freeGameRemain`** | `number` | Number of free spins remaining in the current session. | `FreeGameWriterModule`, `SpinTimesModule` |
| **`freeGameTotalWin`** | `number` | Cumulative win amount inside the active free spin feature. | `FreeGameDirectorModule` |
| **`multiplier`** / **`totalMultiplier`** | `number` | Global multiplier applied to current winnings (e.g. `x2`, `x5`). | `MultiplierModule`, `PaylineInfoModule` |
| **`bonusGameRemain`** | `number` | Remaining picks in Pick-and-Win bonus mode. | `FortuneWheelModuleData`, `BonusTableData` |
| **`bonusValue`** | `number` | Accumulated prize value inside bonus game. | `BonusTableData` |

---

### E. Jackpot & Promotions
| Key Name | Type | Description & Purpose | Downstream Readers |
| :--- | :--- | :--- | :--- |
| **`jackpot`** | `string[]` | Formatted jackpot string array (e.g. `['9000_4_GRAND;2500000']`). | `GameDataStore.getJackpotInfo()` |
| **`trialJpl`** / **`trialJplWin`** | `string[]` | Mock jackpot values for trial play mode simulation. | `TrialModeManager` |
| **`promotionRemain`** | `number` | Remaining promotional free spins count. | `PromotionData` |
| **`promotionTotal`** | `number` | Total promotional free spins originally granted. | `PromotionData` |
