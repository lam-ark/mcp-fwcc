# 💡 Recipe: Setting Up System Toast Notification HUD

---

## 1. Step-by-Step Setup

1. Create a node under `Canvas/Director/Toast`.
2. Attach `ToastInfoModule`.
3. Add child label node `LabelNotify` and link to `lblNotify`.
4. Set `delayTime = 2.0`.
