# 🎰 SpinTimesModule Production Game Case Study

---

## 1. Production Case

In production games (`g9000L` / `g9666L`):
- `SpinTimesModule` displays real-time auto-spin counts over the normal spin button and flips to remaining free spins during Free Game features, formatting unbounded test counts to `'∞'`.
