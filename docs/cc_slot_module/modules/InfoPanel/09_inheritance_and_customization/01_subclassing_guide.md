# 🏗️ InfoPanel Subclassing Guide

---

## 1. Guidelines

1. Extend `InfoPanel`.
2. Populate `titles` array with matching header sprite frames in the Inspector.
3. Call `super.activeButtons(id)` when extending page-turn behaviors.
