# 🚀 TurboButton Game Creation Setup Workflow

---

## 1. Step-by-Step Setup

1. Create a node under `Canvas/Director/UIManager/TurboButton`.
2. Attach `TurboButton`.
3. Add child node `Display` and assign reference in Inspector.
4. Set `sfxTurboOn` and `sfxTurboOff` clip names.
