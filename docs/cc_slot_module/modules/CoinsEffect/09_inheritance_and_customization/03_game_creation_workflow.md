# 🚀 CoinsEffect Game Creation Setup Workflow

---

## 1. Step-by-Step Setup

1. Create a `CoinsEffect` node under the win modal.
2. Attach `CoinsEffect` component.
3. Drag child `cc.ParticleSystem` nodes into `coinParticles` array.
4. Set `.plist` particle asset references in Cocos Editor.
