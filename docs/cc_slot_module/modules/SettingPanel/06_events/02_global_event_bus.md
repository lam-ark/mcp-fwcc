# 🌐 SettingPanel Global Event Bus

---

## 1. Global Events Emitted

| Event | Payload | Purpose |
| :--- | :--- | :--- |
| `TOGGLE_BGM` | None | Toggles BGM active state. |
| `TOGGLE_SFX` | None | Toggles SFX active state. |
| `CLOSE_SETTINGS_PANEL` | None | Closes settings panel. |
| `OPEN_BET_HISTORY_PANEL` | None | Opens Bet History modal. |
| `OPEN_JACKPOT_HISTORY_PANEL`| None | Opens Jackpot History modal. |
