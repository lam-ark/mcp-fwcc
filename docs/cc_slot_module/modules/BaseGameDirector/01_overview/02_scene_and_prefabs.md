# 🏛️ BaseGameDirector Scene Node Placement & Prefab Structure

---

## 1. Inspected Scene Node Placement

`BaseGameDirector` is the foundational base class for all mode director components across mode prefabs under `Canvas/Director/GameMode`:

```text
Canvas/Director/GameMode
├── MainGamePrefab (NormalGameDirectorModule extends BaseGameDirector)
├── FreeGamePrefab (FreeGameDirectorModule extends BaseGameDirector)
└── BonusGamePrefab (BonusGameDirectorModule extends BaseGameDirector)
```

---

## 2. Prefab Wiring & ScriptExecutor Initialization

Each director subclass initializes a dedicated instance of `ScriptExecutor` during `onLoad()` to sequentially process script action queues generated by its companion writer.
