# 🚀 Game Creation Workflow: Adding a Custom Game Mode Director

Follow this 5-step checklist when introducing a new game mode (e.g. `LightningGameDirectorModule`):

---

## Step 1: Create Director and Writer Pair
1. `LightningGameWriterModule.ts`: Defines `makeScriptSpinStart`, `makeScriptSpinResult`, etc.
2. `LightningGameDirectorModule.ts`: Extends `BaseGameDirector`, declares step handler methods.

---

## Step 2: Mount Nodes in Scene Hierarchy
Under `Canvas/Director/GameMode`:
1. Create child node `LightningGame`.
2. Attach `LightningGameDirectorModule` and `LightningGameWriterModule`.
3. In script initialization, link:
   ```typescript
   this.node["director"] = this;
   this.node["writer"] = this.getComponent(LightningGameWriterModule);
   this.init();
   ```

---

## Step 3: Implement Step Handlers on Director
Ensure every command generated by the writer has a matching method on the director:
```typescript
async STOP_LIGHTNING_REEL(data: any): Promise<void> {
    await this.tableModule.stopSpin();
}
```

---

## Step 4: Register Mode in `GameModeDirectorModule`
Add mode mapping in `GameModeDirectorModule` so the master dispatcher can transition into the new mode when `nextMode` matches.

---

## Step 5: Test Execution & Quick-Exit
1. Run spin tests in normal speed, turbo speed, and FTR instant speed.
2. Test clicking Back-to-Real-Mode during an active spin ➔ Verify `forceToExit()` aborts the pipeline cleanly without errors.
