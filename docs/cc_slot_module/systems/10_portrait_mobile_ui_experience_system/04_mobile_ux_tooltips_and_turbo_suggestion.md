# 💡 Mobile UX Tooltips & Turbo Mode Suggestion

---

## 1. Floating Win Breakdown Tooltip (`WinAmountTooltipModule`)
Displays floating badge indicators above winning columns/symbols showing the incremental cash contribution per payline during win rollups.

## 2. Smart Turbo Suggestion (`TurboModeSuggestionPopup`)
Detects when a player completes 15+ consecutive standard spins, intelligently popping up a subtle prompt recommending Turbo Mode for faster gameplay.
